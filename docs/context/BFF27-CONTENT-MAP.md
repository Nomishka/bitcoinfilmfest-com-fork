# BFF27 content map

Status: MVP early-bird page for `/27/`; public launch page, not a final programme or ticket desk.

## Public facts used

- BFF’27 runs 24–27 June 2027 in Warsaw.
- BFF is a Warsaw-born Bitcoin cinema and culture festival built around screenings, filmmakers, art, workshops, music and community programming.
- Ticketing, submission window, exact venue and detailed programme are not yet published on this MVP page.
- The page uses previous-edition public archive images only to communicate atmosphere. They are not presented as BFF’27 event photographs.

- Early-bird CTA sends visitors to `hello@bitcoinfilmfest.com` rather than a dead checkout URL.

- Collaboration CTA links to the shared `/join/` page and a public collaboration email.
- Candidate films in the private BFF27 watchlist are not listed as selections or commitments.
- No exact venue is claimed beyond Warsaw until a public first-party announcement confirms it.
